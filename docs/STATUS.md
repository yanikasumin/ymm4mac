## 監査で確定した残作業（2026-11-17 全体監査 AUD）

全体監査（解析側 `analysis-notes/AUDIT-2026-11-17-FULL.md`、ChatGPT 最終QAで確定）で、従来の残作業リストに載っていなかった未実装・未配線が確定した。AUD-05（台帳の陳腐化）は本バッチで是正済み。

- **AUD-01 EffectItem の描画 Source（本家 EffectSource）が未実装。** `MetalSourceProvider.source(for:)` に EffectItem のケースが無く `MetalEmptySource`（透明）を返す。合成器の FrameBuffer 境界判定でも境界が発生しないため、本家 EffectSource（FrameBufferSource のサブクラス。合成の蓄積画像へ図形パラメータ形状のマスクを適用）の意味論がプレビュー・書き出しの全経路で効かない。本人の検証フィクスチャ kiminihare 両ファイルでは EffectItem が0件のため実ファイルでは踏まないが、一般の本家プロジェクトでは再現が崩れる。
- **AUD-02 トランジション合成（本家 TransitionSource）が未配線。** `TransitionItemPicker` は実装・テスト済みだが合成器から一度も使われず、TransitionItem 自身も空 Source になる。本家は内部に2つの TimelineSource を持ち遷移前後の合成とブレンドを行う。こちらは主合成側の除外規則だけが再現されているため、遷移区間では下位レイヤーが主合成から消える一方、前後合成もブレンドも描かれない。kiminihare 両ファイルでは TransitionItem は0件。
- **AUD-03 クリッピング（IsClippingWithObjectAbove）の実効マスクが未適用。** Core 合成器は `setAlphaMask` まで配線済みだが、`AlphaMaskEffectFactory` の本番実装がリポジトリ内に無く（テストの Fake のみ）、呼び出し側も factory を渡さないため常に nil で、マスク未適用のまま出力が公開される。「1つ上のオブジェクトで切り抜く」はテキスト・字幕・映像の共通プロパティであり影響範囲は広い。
- **AUD-04 PngWav ライター（連番画像＋WAV 書き出し）が未実装。** 本家同梱ライターは FFmpeg / MF / PngWav の3系統で、実装は FFmpeg のみ。MF 相当の未実装は MAC-0017 に記録済みだが、PngWav は台帳に言及が無かったため本項で明記する。
- **AUD-06 Metal 初期化失敗の診断が無い。** `MetalGraphicsDevices` の初期化はシェーダ関数の取得とパイプライン生成の失敗を `try?` で握り、どれか1つでも失敗すると devices 自体が nil になる。PreviewBox と TimelineExporter は nil を返して終わり、プレビュー・書き出しが理由の表示なく成立しない。失敗がエラー型として表面化しない構造。発生条件の現実性（配布形態でシェーダライブラリ不在等が起こりうるか）は未確定。
