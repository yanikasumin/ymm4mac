## 概要

- 正式な開発基準は要件定義 v1.2（解析リポジトリの [REQUIREMENTS](https://github.com/yanikasumin/ymm4-native-research/blob/main/docs/REQUIREMENTS.md)、2026-11-16 発効。CR-001 = macOS 26.0 床、CR-002 = Swift）。対象は macOS 26.0 以降・Apple Silicon 専用。
- 実装は MAC-0001〜0044 とフロントエンドの形（PR #32・#83）まで完了し、モデル層・.ymmp 互換層・描画・音声・書き出し・エフェクト定義層・製品 UI の土台が揃っている。構造整理（コード再編 W1〜W12）は完了。機能フェーズの10単位（音声供給・実時間再生・SOLA・ストリーミング・PngWav・Metal 初期化診断・GPU エフェクト第1弾・ブラシ・変形共通規則・モザイク）は PR #84〜#93 で統合済みで、統合後のフルスイートは 515 件・0 失敗。
- 検証の限界: 本家 YMM4 を動かせる環境が無いため、本家実機との比較（Golden Master）は BLOCKED のまま。検証は本家コードとの照合、実ファイルの読み込み・保存の自己往復（固定点確認）、Mac 実機のビルドとハーネス、全自動テストの実行記録に限定される。

## 主要な未解決

台帳の正本は GitHub Issues。ここには主要なものだけを挙げる。

1. **締切 2026-11-24（UI は本家水準＋内蔵機能網羅）に向けた残作業。** フロントエンドの形の完成（Issue #37〜#42）、素通し32種の実処理化（#45、実プロジェクトでの使用量が最大の Outline から）。VoiceItem の音声供給（#51）は MAC-0040 で接続済み（音声合成エンジン自体は無いため、キャッシュ・カスタム音声の供給のみ）。実時間再生の接続（#52）は MAC-0041・0042 で実装済み（アプリ画面での目視確認が残る）。
2. **監査で確定した残作業。** AUD-04 = PngWav ライター（#49）は MAC-0043、AUD-06 = Metal 初期化失敗の診断表示（#50）は MAC-0044 で解消済み。AUD-01・02・03・07 は MAC-0034〜0036 で解消済み（経緯は IMPLEMENTATION_LOG）。
3. **読み込み対応形式の拡張（Issue #70）。** mkv / webm / ts / avi / ogg は現行の AVFoundation 依存では開けない。設計相談と着工前実測は完了し、基盤（バイナリ解決・プローブ・素材ごとの利用可否の状態モデル）は段階1、映像デコードセッション本体（PTS 基準の選択・TS の出力シーク・セッション管理・失敗状態の駆動）とデコーダ供給の抽象は段階2で実装済み。残りは音声の FFmpeg 実装・Factory 接続・失敗の UI 表示。
4. **統合ブロックのレビュー第6ラウンドは実施済み（2026-11-18）。** 判定は条件付き採用可。P1（リピート再生の再開不良）は R6-01 として処分中。残りの P2・設計残件は台帳の R6-FIX 記録を参照。
5. **Golden Master 比較は BLOCKED。** 本家環境が無い間は到達不能で、代替の検証手段は上記のとおり。

**非対象**: `yanikasumin/YMM4M-custom` は Wine ベースの既存互換環境であり、本ネイティブ移植の開発進捗に算入しない。
